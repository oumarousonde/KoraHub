📖 Comment obtenir la clé Groq
1
Aller sur console.groq.com Connectez-vous avec votre compte existant sur console.groq.com
2
Aller dans "API Keys" Dans le menu de gauche cliquez sur "API Keys"
3
Créer une nouvelle clé Cliquez sur "Create API Key" → donnez un nom comme "KoraHub"
4
Copier la clé Copiez la clé qui commence par gsk_ et collez-la ci-dessus

ElevenLabs API
Génère la voix marketing française masculine pour vos vidéos avatar
✅ 10 000 chars/mois gratuit ⭐ Requis
● Non configuré
📍 Trouvez votre clé sur elevenlabs.io → Settings → API Keys
📍 Trouvez les Voice IDs sur elevenlabs.io/voice-library · Recommandé : "Adam" ou "Antoni"
📖 Comment obtenir la clé ElevenLabs
1
Créer un compte sur elevenlabs.io Allez sur elevenlabs.io et créez un compte gratuit avec votre email
2
Aller dans Profile Settings Cliquez sur votre profil en bas à gauche → "Profile + API Key"
3
Copier votre clé API Dans la section "API Key" cliquez sur l'icône copier
4
Choisir une voix masculine Allez sur Voice Library → filtrez par "Male" → choisissez "Adam" ou "Antoni" → copiez le Voice ID

D-ID API
Génère les vidéos avatar avec un homme africain réaliste qui parle de vos produits
✅ 20 vidéos gratuites ⭐ Requis
● Non configuré
📍 Trouvez votre clé sur studio.d-id.com → Account Settings → API
💡 Utilisez une photo réaliste d'un homme africain en tee-shirt simple · Résolution recommandée : 512x512
📖 Comment obtenir la clé D-ID
1
Créer un compte sur d-id.com Allez sur d-id.com → "Get Started" → créez un compte gratuit
2
Aller dans Account Settings Cliquez sur votre profil → "Account Settings" → onglet "API"
3
Copier votre clé Basic Auth La clé est au format email:token encodé en Base64. Copiez-la directement.
4
Préparer l'image de l'avatar Uploadez une photo sur imgur.com et copiez le lien direct (.jpg/.png)

🚀 Prêt à mettre KoraHub en ligne ?
Suivez les étapes ci-dessous pour déployer KoraHub en moins de 10 minutes
📖 Guide de déploiement Vercel
1
Créer un compte Vercel Allez sur vercel.com → "Sign Up" → connectez-vous avec votre compte GitHub
2
Importer le projet GitHub Dashboard Vercel → "New Project" → sélectionnez votre repo "korahub" → Import
3
Configurer et déployer Vercel détecte automatiquement le type de projet → cliquez "Deploy" → attendez 2 minutes
4
Votre site est en ligne ! Vercel vous donne une URL comme korahub.vercel.app → partagez-la partout !
5
Domaine personnalisé (optionnel) Plus tard vous pouvez acheter korahub.com et le connecter à Vercel facilement
